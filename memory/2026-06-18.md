## Saltwash customer-comms: decided the PDF question

**The debate:** Should printing instructions ship as a PDF in the Etsy download bundle, or in the "Message to buyer" field?

**Context:**
- Etsy digital listings cap at 5 download files (default). To raise, requires Etsy support ticket.
- Saltwash Dog on the Beach lineup uses all 5 slots: `beach-dog-5x7.jpg`, `beach-dog-8x10.jpg`, `beach-dog-11x14.jpg`, `beach-dog-16x24.jpg`, `beach-dog-18x24.jpg`.
- The 2 biggest JPGs (16x24 = 8.7MB, 18x24 = 9.8MB) push a single zip over Etsy's 20MB server-side zip cap. **No zipping the downloads — buyers get files individually.**

**Decision:** Use Etsy's "Message to buyer" field as the primary delivery channel for short printing instructions. Skip the PDF in the download entirely. Reasons:
1. Field is auto-delivered in order confirmation email AND lives on buyer's Purchases page forever
2. Editable without re-uploading
3. The 5-file cap is full; adding a 6th file would require a support ticket for a "nice to have"
4. Standard Etsy print-shop pattern; works for thousands of sale shops
5. The longer reference doc (printing tips, framing, custom-size requests) lives in `saltwash/customer-comms/printing-tips.md` as a copy-paste reference for Catherine when responding to buyer questions

**Files created (committed + pushed to blair-documents, commit 9fd3f5d):**
- `saltwash/customer-comms/message-to-buyer.md` (+ .pdf) — 86-word Etsy message field, universal across all Saltwash print listings
- `saltwash/customer-comms/printing-tips.md` (+ .pdf) — ~310-word copy-paste reference for buyer questions, with quick-reference table for common question patterns

**Key advice baked into both docs:**
- **Paper:** Matte or linen finish, 80–100 lb / 200–270 gsm. Never glossy photo paper (flattens the watercolor texture). Never real watercolor paper (the paper's tooth fights the digital texture already in the image).
- **Printers:** Gelato for online mail-order (single-art-print specialist). Printful works but leans toward their own product line. Staples / FedEx Office for local same-day. Home inkjet works if paper type is set to "matte" or "fine art" in the print dialog.
- **Sizing:** Don't resize — print at the size in the filename. Each file is at print resolution for its target size.
- **Framing:** All 5 sizes fit standard off-the-shelf frames. White border is built in; no mat needed.
- **Custom sizes:** Master is built to handle small edge crops. Ask before promising a non-standard size.

**Voice discipline applied (Catherine's AI-tic audit rules):**
- No triple repetitions
- No "no X, no Y, no Z" negation lists
- One negation list used (`matte or linen... never glossy... never watercolor paper`) — borderline acceptable because it serves a real buyer-confusion point. Could be revised if Catherine flags.
- Sounds like a person who's been to the OBX → ship
