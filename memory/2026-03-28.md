**3. Three Problem Classifications (Stage 3)**

| Problem | Description | Analysis Needed |
|---------|-------------|-----------------|
| A | Inventory missing | Fake buys, partial fake buys, fake returns, shoplifting, employee theft |
| B | Margins low (<59%) | Period Close report (not Item Buy Detail), bad buyers or donated goods |
| C | DRS inventory lower than expected | Solve equation for writeoffs: OH = Buys - Sales + Beginning OH - Writeoffs |

**4. Six Theft Methods (inventory-loss-facts.md)**

1. Classic fake buys (full transaction, never existed)
2. Intermittent fake items (adding 1-3 items after customer leaves)
3. Personal/Goodwill donations (bringing own junk)
4. Physical theft (back door/key holder)
5. Fake returns (pocket cash, item auto-added)
6. Fake damaged/write-offs (write off as damaged, buy garbage from donations in fake names)

**5. Key Framework Insights Added**

- **Data-first approach:** Get Item Buy Detail first → surface suspects → ask owner for clarification (instead of upfront org chart)
- **Date range guidance:** 12-month lookback ending 3 months ago (to filter normal unsold noise)
- **Owner gut instinct matters:** Trust their direction even before data confirms
- **Post-data clarification:** Ask owner about writeoff dates — "clearance vs. cycle count?" Reason codes: "Cycle Count" = physical scan by RGIS/Datascan
- **Clearance schedule question:** Ask if they followed brand schedule (Sept, Jan, Apr, Jun)
- **Store folder naming:** `/documents/pc/pc-8xxxx/` for store-specific work

## Trial Run Feedback (March 28)

**What worked well:**
- Stage 1 questions caught key details (suspect, timeline, key access)
- Data-first approach surfaced suspects quickly
- Mapping "goodwill donations" to Method #6 connected dots

**What to improve:**
- **Ask questions one at a time** — don't dump all Stage 1 questions at once. Ask → wait for answer → note it → ask next.
- **Warehouse key security** — add question: key in safe (who accesses?) or keyring (how secure is purse? any trusted employee with copies?)
- **Check write-off dates against clearance** — if large write-off within ~5 days of month-end (Sept/Jan/Apr/Jun), it's likely clearance, not suspicious. Don't jump to conclusions.

**Updated framework accordingly.**
