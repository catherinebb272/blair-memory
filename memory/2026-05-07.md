- **Login:** heyron.ai/auth/login → magic link with PKCE
- **Callback:** heyron.ai/auth/callback → redirects to user area
- **User subdomain:** user-0241.c1.heyron.ai/sessions (0241 = user ID)
- **Session:** Supabase cookie persists, works across heyron.ai domain
