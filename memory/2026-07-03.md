### The new Saltwash print workflow (LOCKED 2026-07-03, validated on plover)

Replaces the old "native 2:3 + 4:5 crops, then build all 5 sizes as PNGs, then convert to JPGs" pipeline used for beach-dog and beach-walk. The new pipeline is JPG-only, master-first, Photoshop-in-the-loop.

1. **Catherine gives me a raw JPG from Firefly** (or whatever the source is — usually AI-watercolored, may be huge).
2. **I upscale to 18×24 with Lanczos** (Lanczos is the established Saltwash resampler — pure interpolation, no hallucinated detail; matters for watercolor). Flip or other source corrections happen here if needed.
3. **I push the 18×24 review master to GitHub** because the file is too big to send through chat (45 MB PNG / ~12 MB JPG). This is the review step.
4. **Catherine retrieves from GitHub, opens in Photoshop, fixes any AI artifacts or upscaling glitches** (her hand — sometimes gentle clone-stamp work, sometimes nothing, sometimes a re-render).
5. **Catherine returns the cleaned master to me as a JPG** (size still big but manageable, 10-15 MB).
6. **Catherine also saves the cleaned master locally as the print's master file** (the same 18×24 JPG that becomes the Etsy 18×24 upload and the source for downscaling).
7. **I downscale the cleaned master to the other 4 sizes** (5×7, 8×10, 11×14, 16×24) at 300 DPI, with optional per-size crop instructions Catherine gives me (split top/bottom, all from top, recenter the figure, etc.). Default is centered.
8. **I save the entire batch (5 JPGs total) at quality 95** for Etsy upload. If any file creeps over the 20MB Etsy limit, drop to 90 first, 85 only as last resort. For plover, no file hit 12MB at Q95, so no quality drop was needed.
9. **Catherine retrieves the batch from GitHub and uploads to Etsy.**

### Why the workflow changed

- **PNG masters were overkill.** The old beach-dog / beach-walk pipeline kept PNG masters alongside JPGs because PNGs were the original format. For new prints, the source is already JPG (Firefly export) and the deliverable is JPG (Etsy requires <20MB). PNG archival added complexity without benefit.
- **Master-first guarantees consistency.** The old pipeline built 2:3 and 4:5 native crops first, then upscales for 11×14 / 16×24 / 18×24. That meant Catherine was reviewing 2:3 / 4:5 crops in Photoshop, not the final print masters. If she found artifacts, she'd have to fix them across multiple files. The new pipeline: she reviews the actual 18×24 master, fixes once, and the 4 downscaled versions inherit the fix automatically.
- **GitHub as transfer mechanism** because the 18×24 review master is too big to attach in Discord. Pushing to blair-documents branch is the established pattern (last used for plover as branch `beach-plover-print`).
- **Lanczos-only resampling** is the standing decision for Saltwash — confirmed again on the plover at 1.507× upscale (watercolor texture preserved cleanly, no Real-ESRGAN needed).
