### Pipeline math (locked, both prints)

- 5×7 = 1500×2100 px @ 300 DPI (5:7 aspect = 0.714)
- 8×10 = 2400×3000 px @ 300 DPI (4:5 aspect = 0.800, exact match)
- 11×14 / 16×24 / 18×24 = **Catherine's upscale task in Firefly**, not built here
- Native crops (2:3 + 4:5) always saved at source resolution so Catherine can upscale from the master, not from the downscale
- Tool: ImageMagick `convert`, Lanczos filter, `-strip -define png:compression-level=9`

### Gotcha: 5×7 ≠ exact downscale of 2×3

- 2:3 aspect = 0.667, 5:7 aspect = 0.714 (5:7 is wider/shorter)
- ImageMagick's `-resize 1500x2100` on a 2:3 source preserves 2:3 → outputs 1400×2100, not 1500×2100
- Fix: downscale 2:3 → 1500×2250 first, then crop to 1500×2100 (75px off top + 75px off bottom, centered)
- This is why `beach-dog/fix-5x7.sh` exists as a separate script
- Documented in both build scripts and READMEs so I don't relearn this

### Crop bias rule (per source's reported subject position)

- Figure on the right of source → 2:3 crop cuts 2/3 from left, 1/3 from right (beach-dog)
- Figure on the left of source → 2:3 crop cuts 1/3 from left, 2/3 from right (beach-walk, mirror)
- Goal: figure lands at ~1/3 from the SAME side of the final crop, so composition reads as balanced
- Documented in `saltwash/README.md` as a convention for future prints
