### Image prep workflow (locked)

- **Upscale to 7200px on the long edge** — one master file per print, downscale to the 5 delivery sizes.
- **Tool choice:** Upscayl (free, open source, desktop, "Artwork" model) first. Topaz Gigapixel AI ($100 one-time, "Art / Painting" preset) as gold standard fallback.
- **CRITICAL for watercolor: use Art/Artwork preset, NOT Photo mode.** Photo mode over-smooths and kills the texture that makes the work look like watercolor.
- Workflow: upscale → light post-process (color, contrast) → export each size as PNG → bundle into ZIP for Etsy delivery.
