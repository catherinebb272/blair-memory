**Important:** GitHub Actions scheduling is NOT precise. Testing shows:
- Scheduled for 1pm → actually fired at ~1:40pm (40 min late)
- The workflow itself runs fast (9 seconds)
- This is a known GitHub free tier limitation during busy periods
