How I Built This

Cron Reminders via Discord

Project Scope

Set up automated reminders that send Discord DMs at scheduled times throughout the day. These can be daily vitamin reminders, pool maintenance checks, or any recurring task that needs a gentle nudge.

Tools Needed

  • OpenClaw Control - The web interface for your hosted VPS
  • Two ways to do this:
    • Through the UI - Use the Cron Jobs Add Job form in the web interface
    • Through the Agent - Ask your agent to create the cron job via prompt

💡 Note: UI vs Agent

Some users have reported that the UI doesn't save their cron job properly. If you run into that issue, shifting to an agent prompt works great — just describe what you want and let the agent handle the details.

  • Your Discord User ID - To find this:
    • Open Discord Settings → Advanced → Enable Developer Mode
    • Right-click on your username in any chat → "Copy User ID"
    • It's a long number like 881612027863375872

Workflow

Whether you use the UI or the Agent, the Cron Job form has several settings. Here's how to handle each one:

Job Name & Description

Give your job a short, memorable name and optional description. This helps identify it in the cron list.

Schedule

The schedule section has three options:

  • Every - Simple intervals like "every 2 hours" or "every 30 minutes"
  • At - One-time schedule at a specific date/time
  • Cron - Advanced cron expression (5 fields: minute, hour, day, month, weekday)

When you pick Cron, two boxes appear:

  • Cron Expression - The 5-field format (e.g., "0 9 * * *" = 9am daily, "0 13-20/2 * * *" = 1pm, 3pm, 5pm, 7pm)
  • Timezone - Defaults to UTC, so specify your local timezone (America/Chicago, America/New_York, etc.)
Execution
  • Session -
    • isolated - Runs in a separate session. Required for Discord/Telegram delivery.
    • main - Wakes your main conversation quietly. Use this only for background tasks that should NOT interrupt you — no sound, no Discord DM. It's silent.
  • Wake Mode - "now" runs immediately when triggered; "next-heartbeat" waits for the next 30-second heartbeat poll (more efficient, slight delay)
  • What Runs - "post message" for simple text, or "run assistant" if you want the agent to do something first
Prompt

The message you want sent. The key is to be explicit — tell the agent to send a Discord DM to your user ID, and include the exact message text. Vague prompts like "remind me to check the pool" may not trigger the DM.

Better prompt format:

Send a Discord DM to user [YOUR_DISCORD_ID] that says: "Your message here"

This explicit format ensures the agent knows exactly what to do.

Delivery
  • Mode - "announce" delivers to chat, "webhook" sends to a URL, "none" is silent
  • Channel - Usually "last" (your current channel)
  • To - Optional recipient override. For Discord DMs, use "channel:YOUR_DISCORD_ID"

⚠️ The Gotcha

Main session + system-event = NO Discord delivery.

This is the most common mistake. If you want a Discord DM, you MUST use:

  • Session: isolated (not main)
  • Delivery mode: announce (not none)
  • To: channel:YOUR_DISCORD_ID

Pro Tip: Keep the DM Channel Active

🔄 The Keepalive Trick

Discord DM channels can go "stale" when they're inactive for a while, causing cron job deliveries to fail. To fix this, create a keepalive cron job that runs every 10 minutes and sends then immediately deletes a message.

This "pings" the channel open without you ever seeing it. The prompt:

Send me a DM that says 'keepalive' and then delete that message. This keeps the DM channel active without spamming me.

Set it to run every 10 minutes, isolated session, with announce delivery. You won't see the messages, but Discord will keep the channel warm.

Prompts Used

Here are the actual prompts I used to create these reminder jobs:

Daily Vitamins Reminder (9am Chicago)
Create a cron job that runs every day at 9am Chicago time. Use timezone America/Chicago. Use isolated session with --announce to deliver to Discord channel [YOUR_DISCORD_ID]. Use --message "Take your vitamins 💊". Use next-heartbeat wake mode.
Pool Skimmer Reminder (multiple times per day) - FIXED VERSION
Create a cron job that runs every 2 hours between 1pm and 8pm Chicago time. The cron expression is "0 13-20/2 * * *" which covers 1pm, 3pm, 5pm, and 7pm. Use timezone America/Chicago. Run in the isolated session with --announce to deliver to Discord. Send a Discord DM to user [YOUR_DISCORD_ID] that says: "Hey! Go check the pool skimmers. Don't make me come up there 👀". Use next-heartbeat wake mode.
Keepalive (runs every 10 minutes)
Create a cron job that runs every 10 minutes. Use timezone America/Chicago. Run in the isolated session with --announce to deliver to Discord. Send a Discord DM to user [YOUR_DISCORD_ID] that says "keepalive" and then immediately delete that message. Use --expect-final so the agent waits for completion. Use now wake mode.

✅ Typical Confirmation

When the agent successfully creates the job, it will return something like this:

Done. Created "pool-skimmer-reminder" — runs at 1pm, 3pm, 5pm, and 7pm Chicago time. First one should fire in ~20 minutes (1pm Chicago = 6pm UTC). "Hey! Go check the pool skimmers. Don't make me come up there 👀"

Key Takeaways

  1. Want a Discord DM? Use isolated + announce + --to "channel:YOUR_ID"
  2. Be explicit in the prompt: "Send a Discord DM to user [ID] that says: '...'"
  3. Always specify timezone or it defaults to UTC
  4. Main session is for silent background tasks only (no DM)
  5. Use a keepalive cron (every 10 min) to prevent DM channel from going stale
  6. If the UI fails, shift to an agent prompt — it works great!
