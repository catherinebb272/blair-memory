How I Built This

Animated Avatar Project

Project Scope

Create animated avatar videos for Apart Not Alone (ANA) sobriety milestone coins using AI voice generation and lip-sync technology. The goal is to produce engaging 5-second animated content featuring our otter avatar that can be used for social media and marketing.

Tools Needed

  • ElevenLabs - For text-to-speech voice generation (requires API key)
  • LipSync AI - For creating lip-synced animations from static images
  • Otter avatar image - PNG/JPG with clear face/mouth area
  • Voice script - 5-second script for the audio

Workflow

  1. Provide ElevenLabs API key - Give your API key to the agent for TTS generation
  2. Choose a voice - Select from available voices (Sarah, Laura, Jessica, Bella, etc.)
  3. Generate voice audio - Have the agent create the TTS audio file
  4. Go to LipSync AI - Visit https://lipsync.video/
  5. Upload otter image - Use your avatar image
  6. Upload audio - Use the generated voice file
  7. Generate & download - Create and save the animated video

Prompts Used

**Prompt for Voice Generation** "We need to set up ElevenLabs to generate a voice sample for our otter avatar. Generate a 5 second test sample using [voice name] with the script: [your script text here]." --- **Prompt for LipSync Setup** "We need to set up LipSync AI to create a sample animation. Talk me through creating a free 5 second animation of our [otter] avatar using the image and voice script we already created."
