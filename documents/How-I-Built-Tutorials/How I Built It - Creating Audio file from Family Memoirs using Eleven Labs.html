How I Built This

Creating Audio file from Family Memoirs using Eleven Labs

Project Scope

The goal of this project is to convert typewritten family memoirs into digital audio files for each chapter, making them accessible and preserving them for future generations.

Tools Needed

  • Memoir Source: Digitized text files of family memoirs (originally typewritten, then retyped).
  • Transcription Input: Agent will handle PDF conversion if scanned documents were used.
  • Method for uploading/retrieving text: Email (via Agentmail), GitHub, or direct attachment in Discord.
  • ElevenLabs Account: A free plan is sufficient for small jobs. Need to create an account and select a voice.
  • Tutorial Resources: Access to Thedenheyron.com (Training tab) for guidance on connecting email, GitHub, and ElevenLabs. Specific resource for Audio Visual (module 5) for ElevenLabs setup.

Workflow

  1. Prepare the Memoir Text: Ensure the family memoirs are available in a digital text format. If originally scanned PDFs, convert them to text. (In this case, they were retyped.)
  2. Upload Memoir Text to Agent: Method Options: Email via Agentmail, GitHub, or Discord Attachment. Guidance: For tutorials on connecting email, GitHub, or handling attachments, refer to Thedenheyron.com > Training tab.
  3. Configure ElevenLabs Integration: Create an account on ElevenLabs.io. Utilize the free plan. Select a voice and add it to "My Voices" tab. Ensure the agent has access to ElevenLabs (follow tutorial on "Audio Visual" module 5).
  4. Script Creation and Refinement: Prompt the agent to create a script for the audio file, based on the memoir text. Instruct the agent to incorporate emotion tags for added realism where appropriate. Review and revise the generated script for accuracy, tone, and flow.
  5. Audio File Generation: Prompt the agent to use the final script and the selected ElevenLabs voice to create the audio file for each chapter.
  6. Troubleshooting Potential Issues: Address voice issues, character limits, etc.
  7. Retrieve the Audio File: Prompt the agent to return the generated audio file(s). Email Delivery can be configured using Agentmail.

Prompts Used

Step 1 Prompt to get the text extracted "Please extract the text from the attached document (or from the file at this link: [provide link here if applicable]). Once extracted, please deliver the text to me in the chat window. If that's not possible, please email it to me at [your email address] I need to proofread it. Step 2: Prompt to install Agentmail [If Needed]. "Connect Agentmail. Here is the link to all agentmail documentation https://docs.agentmail.to/llms.txt . Talk me through the installation process, including signing up for the account and getting an API key. Do a test email." Step 3: Prompt to configure ElevenLabs "Connect to ElevenLabs. Talk me through the installation process, including signing up for the free account and getting the API key, choosing a voice and troubleshooting any problems. Once connected, do a test audio sample and attach it as an audio message in Discord [or Telegram]. If there is a limitation on voices, talk me through selecting a compatible voice." Step 4: Prompt to create final script for Eleven Labs. "Using the text you extracted [or if changes were made, the script attached], please review and add punctuation as needed for pacing. Also provide recommended tags for additional emotion and realism in the elevenlabs conversion. Suggested tags can be found here: https://medium.com/@v-jur-kh/on-text-markup-for-the-elevenlabs-v3-text-to-speech-2b0a330110e1. Tags are placed before the word or phrase to be modified. Put the revised script with suggested tags [in this chat] [email] for me to review and approve." Step 5-6: Prompt to execute the script in ElevenLabs "Using our final agreed script, use the ElevenLabs text to speech conversion to create an audio file for me to listen to and approve. Give the file to me [in this chat] or [by email ] for final approval. Talk me through any troubleshooting required if the file doesn't create properly. Ask me if the file meets expectations or if anything needs to be changed. Step 7: Prompt to save final work product "Please save this audio file and call it [project name] in folder [project folder name]. . If we configured any tools today, please update memory, tools or other files with that information for future use. Update memory logs to include what we did in this project. "

Tips & Tricks

  • If the material is large, you cannot paste it directly in Discord - use file upload
  • Create smaller sections first to test out ElevenLabs voice effects without burning through credits
  • Long chapters may exceed the available character plan limit in ElevenLabs free plan, so break into sections over time.
