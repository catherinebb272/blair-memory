## Columns
- **SKU** — internal ID
- **Product Name** — Etsy title (search-optimized)
- **Line** — product line / collection
- **Format** — `digital` | `physical` | `both`
- **Price (USD)** — retail
- **Phrase / Sayings** — primary text on product
- **Status** — see legend below
- **Image / Asset** — link to art file
- **Notes** — pending, line association, character/visual TBD, etc.

## Status legend
- `concept` — idea only, no art yet
- `prototype` — in development / first samples / Barbara reviewing
- `listed` — on Etsy, live
- `active` — listed and selling
- `archived` — discontinued

## Why Material first

Recommended structure, not yet finalized — flag if you want to flip it.

**Material first (current):**
- Matches how Etsy organizes listings (product type = category). Customer browsing "greeting cards" sees all of ANA's cards.
- Matches Printify production templates (card stock, die cut, sheet are different production SKUs).
- Easier to maintain: when a new line drops, you add a section row, not empty sub-sections across every line.
- Tiny Victories and Sticker cross-pollination still works — the Appendix gives you the collection view when you need it.

**Collection first (alternative):**
- Customer-oriented: "I want Tiny Victories stuff" → all merch in one place.
- Better for cross-merch / bundling ("buy the card + the matching sticker").
- Cons: empty sections for lines with only one material type, harder to keep in sync as new lines appear.

**Verdict:** Material first as primary, with the Collection cross-reference appendix. Get the simplicity of your original structure and the cross-merch view as a lookup, not a hierarchy.
