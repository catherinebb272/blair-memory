# Journal Sample Pages

**Folder:** `documents/ana/journal/sample-pages/`
**Purpose:** Production-ready prompts for ChatGPT image generation, plus plain-text page specs that Barbara/Catherine can render in Canva or InDesign.
**Workflow:** Catherine generates a mockup image in ChatGPT using the prompt below → renders/edits in Canva → drops in coin photos → final POD upload.

---

## How to Use These

1. Pick the sample page (intro, daily, weekly, or milestone).
2. Copy the **ChatGPT image-generation prompt** into ChatGPT (use a model with image generation, e.g., GPT-4o or GPT-5 with image output).
3. ChatGPT returns a flat 2D page mockup. Use this as the **layout reference**.
4. Open the same page in Canva. Drop in actual coin photos from `/assets/coins/`. Add the ANA logo (when provided). Refine typography.
5. Export the Canva page as a high-res PDF page. This is the production asset.
6. When all sample pages are approved, Barbara/Catherine bulk-renders the remaining 12 milestone pages + 90 daily pages + 40 weekly pages in the same template.

---

## Master Style Tokens (use across all sample pages)

Copy this block to the top of every ChatGPT prompt so the style stays consistent:

```
STYLE TOKENS — paste this block at the top of every prompt:
- Page size: 6 inches wide × 9 inches tall (US trade paperback trim)
- Paper: soft linen cream (#F5EFE8), matte, no texture
- Neutral inks (fixed across all pages): warm charcoal (#2A2826) for body text, pencil-gray (#D8D2C5) for rule lines (0.5pt)
- Accent ink: a single saturated ANA color per page — pick ONE from the palette below. Used only on the title, prompt labels, the ANA logo, the attribution, and a soft ~10% opacity circular wash behind the coin. Everything else is cream or charcoal.
- ANA palette (saturated, pick one primary per page):
    #003B88 ocean indigo
    #37C86F leaf green
    #4D7BCC medium blue
    #FF5D4C sunrise coral
    #FFD437 golden sunrise
    #F5EFE8 soft linen (paper — never use as ink)
- ANA palette (lighter unsaturated versions, used as the accent + tint behind the coin):
    soft sky tint of #003B88
    soft mint tint of #37C86F
    soft periwinkle tint of #4D7BCC
    soft peach tint of #FF5D4C
    soft butter tint of #FFD437
- Typography pairing: Serif body (EB Garamond or Lora), clean sans headers (Inter)
- Margins: 0.75 inch all sides
- No borders, no decorative frames, no clipart
- Single coin photo or single line-art icon per page max
- Brand mark: small ANA logo (two fish in a circle, line drawing) in bottom-right corner of every interior page, 0.5 inch, inked in the page's primary color
- Aesthetic: modern, calm, grounded. Like a museum catalog page. Not a greeting card. Not a workbook. Not "woo woo" recovery.
- No religious language. No script fonts. No "One Day at a Time." No 12-step references.
- Photographic style for mockup: top-down flat-lay, even daylight, no shadows, no hands, no props. The page sits alone on a slightly darker cream background for the mockup only.
- The page should feel overwhelmingly calm — cream, charcoal, pencil-gray — with one or two moments of color. The coin's color is the loudest thing on the page.
```
