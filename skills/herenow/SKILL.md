# here.now Skill

## Purpose
Publish static sites to here.now hosting service.

## Environment Variables
- `HERENOW_API_KEY` - API key

## Usage
```bash
# Publish static site
# 1. Get file metadata
# 2. PUT to presigned URLs
# 3. POST to finalizeUrl

# Live site: https://boreal-larch-wxxv.here.now/
# Source: nc/neighborhoods/
```
