## Notes for Drew

- **Pick based on customer vibe:** Some prefer simple, others like more emotion
- **Vary versions:** Don't use the same version twice in a row if shipping multiple coins
- **Handwriting tips:**
  - Use unlined cardstock for a polished look
  - Dark ink (Navy or Black) reads best
  - Keep it brief — 3-4 sentences max
  - One emoji, placed at the end
