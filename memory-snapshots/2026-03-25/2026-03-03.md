# 2026-03-03 - Font Software Research

## Handwriting-to-Font Options

### Option A: Calligraphr
- **Pricing:** Free tier (limited) or $8/month ($96/year) for full features
- **How it works:** Print template → write letters → scan/upload → generates font
- **Best for:** True handwriting replication, quick personal fonts
- **Note:** Subscription model, not one-time purchase

### Option B: Fontself
- **Pricing:** One-time purchase - $49 for Illustrator OR $49 for Photoshop (iPad version $39)
- **How it works:** Plugin for Adobe apps - draw vectors, click export to font
- **Best for:** Stylized/concept fonts, if already using Adobe Creative Cloud
- **License:** Perpetual, commercial use allowed

## Option B: Cricut Design Space Workflow

### Illustrator: Handwriting to Vector Paths (5 Steps)

**Step 1: Scan Your Handwriting**
- Use a dark pen (black or deep blue) on white paper
- Scan at 300 DPI or higher (color or grayscale)
- Save as PNG or JPG

**Step 2: Import to Illustrator**
- File → New → pick standard size
- File → Place → select scanned image
- Window → Layers → lock layer and dim to 50%

**Step 3: Auto-Trace (Image Trace)**
- Select image, Window → Image Trace
- Mode: Black and White, Threshold ~128
- Paths: More Accurate, Corners: Middle, Noise: ~10px
- Click Trace, then Expand

**Step 4: Clean It Up**
- Zoom in, use Direct Selection Tool (A) to delete stray points
- Select all paths → Object → Path → Simplify

**Step 5: Export as SVG**
- File → Save As → SVG (svg)
- SVG 1.1 default settings

### Cricut Design Space (6 Steps)

1. Upload → Upload Image
2. Select your SVG file
3. Import should auto-detect as "Draw" lines
4. Insert → resize → position on canvas
5. Attach to your project
6. Load pen → mat → go

### Pro Tips

- Write larger than needed — small handwriting traces messy, scale down in Cricut
- Use simple strokes — cursive connects naturally, printing works too
- Test one letter first before tracing full alphabet
