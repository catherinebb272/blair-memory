# PROBE CONTROLLER

Goal: Test core capabilities of this environment.

Steps:

1. File Write Test
2. File Read Test
3. File-to-File Instruction Test
4. State Persistence Test

---

## STEP 1: WRITE TEST

Create a file named:
probe_output.md

Contents:
"File write successful"

Then proceed to Step 2.

## STEP 2: READ TEST

Open and read `probe_output.md`. If the contents match "File write successful", report "READ SUCCESS"; otherwise report "READ FAILED OR CONTENT MISMATCH".

## STEP 3: FILE‑TO‑FILE INSTRUCTION TEST

If the read was successful, create a file named `state_summary.md` with the line:
"State persisted after read."

## STEP 4: STATE PERSISTENCE TEST & FINAL REPORT

Read `state_summary.md`. If it contains the expected line, output a final summary:
"All steps completed successfully. State persisted across write and read."
Otherwise, report the failure.
